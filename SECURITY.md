# Security reporting

Do not put credentials, private reports, recordings or a working exploit against user accounts in a public issue.

Use this repository's private vulnerability reporting feature if enabled. Otherwise contact the repository owner through an already verified private channel and agree on a secure way to share details. This project does not publish an unverified security email address.

Include the affected commit, expected boundary, minimal reproduction using synthetic accounts, impact and a suggested fix if available. No response-time or bounty commitment is made.

The implementation's current boundaries and operational requirements are documented in [docs/SECURITY.md](docs/SECURITY.md). Hosted integration and an independent security review are still required before broad public use.
